# 流式说话人确认 — 使用手册

diart 流式说话人确认功能：在实时说话人分割的同时，将每位说话人与注册声纹库比对，确认后以**真实人名**输出（如 `speaker0 → 王佳琪`），未注册说话人保持 `speakerX` 标签。

---

## 1. 环境准备

### 1.1 Python 环境（推荐 conda）

```bash
conda env list          # 本机已有 diart 环境
conda activate diart    # Python 3.10, torch 2.13 (CPU), pyannote.audio 4.0.7
```

如从零创建：

```bash
conda create -n diart python=3.10 -y
conda activate diart
pip install -r requirements.txt
```

### 1.2 模型准备（本机已下载，可跳过）

HuggingFace 直连受限，模型从 ModelScope 下载到项目 `models/` 目录：

```bash
modelscope download --model pyannote/segmentation-3.0 --local_dir models/segmentation-3.0
modelscope download --model pyannote/wespeaker-voxceleb-resnet34-LM --local_dir models/wespeaker-voxceleb-resnet34-LM
```

- `segmentation-3.0`：VAD + 说话人分割（5.9MB）
- `wespeaker-voxceleb-resnet34-LM`：256 维声纹模型（26.6MB），**注册与识别共用此模型**（保证同一向量空间）

## 2. 声纹库准备

目录结构：**每个说话人一个子文件夹**，文件夹名即人名，内含任意数量音频（wav/m4a/mp3/flac/amr）：

```
声纹库/
├── 王佳琪/
│   ├── 王佳琪_1.wav
│   ├── 王佳琪_2.wav
│   └── 王佳琪_3.wav
├── 李笑康/
│   └── 李笑康_1.wav
└── 贺文泰/
    └── ...
```

- 每个说话人建议 ≥ 2 段、每段 ≥ 3s 的干净录音（参考本机测试数据：`test_spk/说话人识别测试/声纹库/`，10 人 × 1~3 段）；
- 注册时自动重采样 16kHz 单声道，3s 窗/1.5s 步滑窗提取声纹，单文件最多取前 30s；
- 注册在服务/管道启动时执行一次（10 人约 30–60s CPU），启动日志打印每人注册条数：
  ```
  [声纹注册] 贺文泰: 3 个文件, 7 条声纹, 256 维
  [说话人确认] 已加载 10 个注册说话人, 阈值 0.5, 确认所需连续chunk数 3
  ```


运行中控制台实时打印确认事件：


输出 RTTM 文件（`--output` 指定目录）中的标签即真实人名。

### 3.2 WebSocket 服务（serve 模式，对接前端/客户端）

serve 与 web 控制台支持两种说话人模式，可运行中即时切换（无需重启）：

| | 确认模式（verify，默认） | 识别模式（identify） |
|---|---|---|
| 标签替换 | 连续 min_chunks 次相似度 ≥ 阈值才替换 | EMA 平滑后即时替换 Top-1（无门禁） |
| 低于阈值 | 保持 `speakerX`（未注册不替换） | 保持 `speakerX`（open-set） |
| 名字变化 | 稳定（确认后锁定，误确认自动撤销） | 即时跟随 Top-1（含改回 speakerX） |
| 附加输出 | `speaker_verification`（确认映射） | `speaker_verification`（含 top3 候选） |

```bash
# serve 以指定模式启动（默认 verify）
PYTHONPATH=src python -m diart.console.serve --verify-mode identify ...

# 运行中切换（WebSocket 控制消息，web 控制台点击按钮即可）
# 浏览器 -> web_ui({"type":"mode","mode":"identify"}) -> serve
```

web 控制台操作：`http://127.0.0.1:8003` →「推理服务连接」卡片新增**说话人模式**切换按钮（确认/识别），点击即生效（需 serve 以 `--voiceprint-dir` 启动，否则提示无确认功能）。

识别模式端到端实测（EER 阈值 0.5，5 会议）：人名覆盖率 59–83%（确认模式 57–81%），open-set 下低相似段仍保持 `speakerX`。

```bash
# 启动服务端（默认端口 7007）
PYTHONPATH=src python -m diart.console.serve \
  --voiceprint-dir test_spk/说话人识别测试/声纹库 \
  --segmentation models/segmentation-3.0 \
  --embedding models/wespeaker-voxceleb-resnet34-LM \
  --cpu --host 127.0.0.1 --port 7007 --output /tmp/serve_out
```

```bash
# 另开终端：发送音频文件（或 microphone）
PYTHONPATH=src python -m diart.console.client \
  test_spk/说话人识别测试/拼接会议/音频/外部客户合作对接洽谈会议_完整版.wav \
  --host 127.0.0.1 --port 7007 --sample-rate 16000
```

客户端实时收到 RTTM 行，已确认段的人名为真实姓名：


## 4. 参数说明

### 4.1 说话人确认参数（stream / serve 通用）

| 参数 | 默认 | 说明 |
|---|---|---|
| `--voiceprint-dir` | 无 | 声纹库目录；**不提供则关闭说话人确认**（纯 diarization） |
| `--verify-threshold` | 0.5 | 余弦相似度确认阈值（**EER 校准值**，`scripts/calibrate_threshold.py` 计算；参考项目经验值 0.4 已弃用）；调大更严格、误报少、召回降 |
| `--verify-min-chunks` | 3 | 确认所需连续命中 chunk 数（=撤销所需连续不达标数） |
| `--verify-ema-alpha` | 0.3 | 相似度 EMA 平滑系数；调小更抗抖、确认更慢 |
| `--no-verify` | - | 显式禁用说话人确认 |

### 4.2 阈值校准（EER，pyannote 官方策略迁移）

默认阈值 0.5 来自 EER 校准（用带真值的会议数据构建同人/异人验证对）：

```bash
# 用 test_spk 的 5 个会议真值段校准（输出阈值与 FAR/FRR 曲线）
diart_env python scripts/calibrate_threshold.py
# docs/results/calibration/threshold.json + eer_curve.png
```

本机校准结果：同人 316 对（均值相似度 0.824）/ 异人 4,909 对（均值 0.210），**EER=0.6% @ 阈值 0.50**；FAR≤1% 阈值 0.47、FAR≤5% 阈值 0.405。三档阈值端到端对比（5 会议 2,663 段）：0.4 → 59.6%、0.47 → 69.2%、**0.5 → 71.4%**（默认值，最优）。更换数据域时建议重新校准。

### 4.3 管道参数（影响确认效果）

| 参数 | 默认 | 说明 |
|---|---|---|
| `--delta-new` | 1 | 新说话人聚类距离阈值。wespeaker 下建议 **0.6~0.8**（1.0 易合并说话人，过小易碎片化） |
| `--tau-active` | 0.5 | 活跃说话人判定阈值 |
| `--duration / --step / --latency` | 5 / 0.5 / 0.5 | 窗口 / 步进 / 延迟（秒） |
| `--max-speakers` | 20 | 最大跟踪说话人数 |
| `--cpu` | GPU 优先 | 强制 CPU 推理 |
| `--output` | 无 | RTTM 输出**目录**（serve 的 URI 含端口号，文件名形如 `127.0.0.1:7007.rttm`） |

## 5. Python API

### 5.1 管道级（推荐）

```python
from diart import SpeakerDiarization
from diart.blocks import SpeakerDiarizationConfig

pipeline = SpeakerDiarization(SpeakerDiarizationConfig(
    voiceprint_dir="/path/to/声纹库",   # 启用说话人确认
    verify_threshold=0.5,
    verify_min_chunks=3,
    verify_ema_alpha=0.3,
    # 模型（本机本地路径）
    # segmentation=m.SegmentationModel.from_pretrained("models/segmentation-3.0"),
    # embedding=m.EmbeddingModel.from_pretrained("models/wespeaker-voxceleb-resnet34-LM"),
))

from diart.inference import StreamingInference
from diart.sources import FileAudioSource

source = FileAudioSource("audio.wav", 16000, (0, 0), 0.5)
inference = StreamingInference(pipeline, source, batch_size=1, do_plot=False)

def on_chunk(ann_wav):
    ann, _ = ann_wav
    # ① 标签已是真实人名（已确认段）
    # ② 每 chunk 的确认状态：
    print(ann.speaker_verification)
    # => {0: {'name': '王佳琪', 'id': '', 'similarity': 0.612}, ...}

inference.attach_hooks(on_chunk)
prediction = inference()
```

### 5.2 验证器级（自定义接入）

```python
from diart.verification import (
    DirectoryVoiceprints, DBVoiceprints, StreamingSpeakerVerifier,
)

# 注册源 1：目录
provider = DirectoryVoiceprints("声纹库", embedding_model, device=device)
voiceprints = provider.load()

# 注册源 2：PostgreSQL（参考项目 256 维三表结构，需 pip install psycopg[binary]）
provider = DBVoiceprints(dsn="postgresql://postgres:postgres@127.0.0.1:5432/ai_meeting2")
voiceprints = provider.load()

# 流式确认器
verifier = StreamingSpeakerVerifier(
    voiceprints, threshold=0.5, min_chunks=3,
    ema_alpha=0.3, unconfirm_min_chunks=None,  # None = 同 min_chunks
)
# 每个 chunk 调用（centers 来自 OnlineSpeakerClustering）
confirmed = verifier.update(centers, active_speakers)   # {spk_idx: VerifiedSpeaker}
annotation = verifier.rename_annotation(annotation)     # 原地改名
```

## 6. 输出解读

### 6.1 标签规则

| 情况 | 输出标签 |
|---|---|
| 已注册且确认（≥3 chunk 相似度 ≥0.5） | 真实人名（如 `王佳琪`） |
| 未注册 / 未达标 | `speakerX`（**不替换**） |
| 曾确认后相似度持续 <0.5 | 撤销确认，恢复 `speakerX` |

### 6.2 annotation.speaker_verification

每个输出 Annotation 携带的确认状态快照：

```json
{0: {"name": "王佳琪", "id": "", "similarity": 0.612},
 1: {"name": "李笑康", "id": "", "similarity": 0.531}}
```

`similarity` 为当前 EMA 平滑后的余弦相似度；`id` 仅 PostgreSQL 注册源有值。

## 7. 常见问题（FAQ）

**Q1：启动很慢？**
模型加载 + 声纹注册（10 人约 30–60s CPU）在启动时一次性完成，属正常现象；注册结果缓存，不重复计算。

**Q2：确认延迟多久？**
理论 ≈ `min_chunks × step`（默认 1.5s）+ EMA 爬坡，实测 2–5s。

**Q3：名字老是不出现 / 认错人？**
- 调小 `--delta-new`（0.6~0.8）减少说话人合并；
- 提高 `--verify-threshold`（0.5~0.55）进一步减少误报（召回相应下降）；降低则提升召回；
- 检查声纹库录音质量与时长（建议每人数段、共 10s+ 以上）。

**Q4：CPU 跑得动吗？**
本机实测 0.11s/chunk，约 5–9 倍实时（5s 窗口处理 0.5s 音频耗时 0.11s），可满足实时会议。

**Q5：识别过程中新增注册声纹？**
当前需重启服务重新加载声纹库（`DirectoryVoiceprints.load()` 有缓存）。

**Q6：服务端 RTTM 文件名带冒号？**
serve 模式 URI 为 `host:port`，输出文件名形如 `127.0.0.1:7007.rttm`，属正常。

## 10. 临时声纹库与 UI 添加声纹

运行时**热添加声纹**（无需重启服务）：serve 同时从主库 + 临时库注册，web 控制台上传音频即可添加。

```bash
# 1. 启动 serve（带临时库；web_ui 与 serve 的临时库路径必须一致）
python -m diart.console.serve --voiceprint-dir 主声纹库 --temp-voiceprint-dir temp_voiceprints ...
python -m diart.console.web_ui --temp-voiceprint-dir temp_voiceprints ...

# 或直接用启动脚本（已配置好临时库）
bash scripts/run_server.sh   # 终端 1
bash scripts/run_ui.sh       # 终端 2
```

**操作**：浏览器 `http://localhost:8008` →「添加声纹（临时库）」卡片，两种录入方式：
1. **文件上传**：填写说话人姓名 + 选择音频文件 → 点击"＋ 添加声纹"
2. **麦克风录音**：填写说话人姓名 → 点击"🎙 录音"直接对着麦克风说话（建议 5–15 秒，自动停止上限 15s，可提前点"⏹ 停止"）→ 停止后自动编码为 WAV 并上传

**机制**：
- 音频保存到 `<临时库>/<姓名>/<时间戳>.<ext>`（wav/m4a/mp3/flac/amr，≤50MB）
- 会话进行中：自动通知 serve **热重载**（重建注册矩阵，已确认的说话人状态保留）
- 无会话时：暂存标记，下次会话开始时自动补发重载
- 主库与临时库**同名说话人声纹合并**（增量补充，不覆盖）

**REST API**（供脚本/自动化使用）：
```bash
# 添加声纹
curl -X POST http://localhost:8003/api/voiceprints \
  -F "name=王小明" -F "audio=@/path/to/voice.wav"
# 查看临时库
curl http://localhost:8003/api/voiceprints
```
